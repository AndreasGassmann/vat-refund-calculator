# VAT Refund Calculator

Compare product prices abroad with local alternatives in your currency. Enter a product's EUR price, and the app converts it to CHF, deducts German VAT (19%), adds Swiss VAT (8.1%), and shows how much you'd save versus buying locally.

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

React 18, TypeScript, Vite, React Router
